# Брамида Прокат — CRM

Веб-приложение (PWA) для проката автомобилей: брони, календарь, клиенты, платежи, расходы, договоры.

- Открыть: https://milianforz-prog.github.io/bramida-crm/
- Данные хранятся в Supabase и доступны только сотрудникам из «Настройки → Команда». В этом репозитории только код приложения, данных клиентов здесь нет.
- Установка на телефон: iPhone — Safari → «Поделиться» → «На экран Домой»; Android — Chrome → ⋮ → «Установить приложение».
